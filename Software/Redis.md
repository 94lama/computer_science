Il REmote DIctionary Server è un tool utilizzato (in particolare dalle applicazioni serverless e le applicazioni basate sui micro-servizi) per consentire alle varie funzioni di comunicare o ricordare delle informazioni (rendendole da stateless a stateful) tramite l'utilizzo di cache.

Funziona come servizio multiutente (ad ogni utente viene assegnato un prefisso)
