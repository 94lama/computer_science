# Keywords

## \#region
Permette di creare una sezione di codice.

```file
#region Nome
<codice>
#endregion Nome
```

La keywork deve essere commentata quindi, mentre nel caso di linguaggi come PHP e Python, il cancelletto (#) basta per iniziare l'area dei commenti, per altri linguaggi si deve creare appositamente un'area di commento, ad esempio:

```JavaScript
// #region Nome
console.log("Questa è la regione Nome");
// #endregion Nome
```

Le regioni sono comprimibili (tramite freccetta a inizio riga).
